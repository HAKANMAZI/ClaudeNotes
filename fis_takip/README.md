# Fiş Takip / Receipt Tracker 🧾

**TR:** Market, yakıt ve diğer fişleri fotoğraftan okuyan, takvimli kişisel bütçe uygulaması. Fişsiz harcamalar, gelir, yatırım, birikim ve istatistikler.

**EN:** A personal budget app that reads grocery, fuel and other receipts from photos, with a calendar, expenses without receipts, income, investments, savings and statistics.

| | Türkçe | English |
|---|---|---|
| Web | [web/](https://hakanmazi.github.io/ClaudeNotes/fis_takip/web/) | [web/en/](https://hakanmazi.github.io/ClaudeNotes/fis_takip/web/en/) |
| Android APK | [fis-takip-tr.apk](https://github.com/HAKANMAZI/ClaudeNotes/releases/download/fis-takip/fis-takip-tr.apk) | [fis-takip-en.apk](https://github.com/HAKANMAZI/ClaudeNotes/releases/download/fis-takip/fis-takip-en.apk) |

Uygulama içinde sağ üstteki **EN / TR** düğmesiyle dil değiştirilebilir.
Fiş okuma için kendi Anthropic API anahtarın gerekir (⚙️ ayarlar). Veriler cihazda saklanır.

## Klasörler
- `web/` - Bağımsız web sürümü (Türkçe), `web/en/` İngilizce
- `android/` - Android uygulaması; APK GitHub Actions ile derlenir
- `artifact/` - claude.ai üzerinde çalışan sürüm ve eski sürüm yedekleri
- `streamlit/` - Streamlit sürümü
- `server/` - Kendi sunucunda çalışan Express sürümü
