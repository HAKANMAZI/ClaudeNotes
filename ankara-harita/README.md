# Ankara Gezi Haritası

Ankara'nın ünlü mekanlarını, AVM'lerini, okullarını ve camilerini gerçek harita üzerinde gösterir. Bir noktaya dokununca özet bilgi açılır.

- Tek dosya: `index.html`. Kurulum gerekmez.
- Harita altlığı: OpenStreetMap (Leaflet 1.9.4).
- Yayınlamak için depo ayarlarından GitHub Pages'i açın.
- Bazı konumlar yaklaşıktır.
