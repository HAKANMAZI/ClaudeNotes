KURULUM
1. Consoles -> Bash aç ($ işareti olmalı, >>> değil) ve yaz:
   git clone https://github.com/HAKANMAZI/ClaudeNotes.git
2. Web -> Add a new web app -> Manual configuration -> en yeni Python.
3. WSGI configuration file içeriğini sil, şunu yapıştır, Save:
   import sys, os
   sys.path.insert(0, '/home/hak122hak1/ClaudeNotes/kare')
   os.environ['SECRET_KEY'] = 'uzun-rastgele-bir-yazi'
   from app import app as application
4. Web -> Reload.

GÜNCELLEME
Bash'te: cd ClaudeNotes && git pull   ->   Web -> Reload

BAKIM
Ayda bir Web sekmesindeki "Run until ..." düğmesine bas, yoksa site kapanır.

HATALAR VE ÇÖZÜMLER
- ">>>" ekranında "SyntaxError: invalid syntax":
  Python konsolu açık, Bash değil. Bu ekranda şöyle yaz:
  import os; os.system("cd ~/ClaudeNotes && git pull")
  Ya da Consoles -> Bash aç ($ işareti olmalı).
- Bilgisayarda "'git' is not recognized":
  Komut kendi cmd'nde yazılmış. PythonAnywhere Bash'te yaz.
- "destination path 'ClaudeNotes' already exists":
  Klasör zaten var. git clone yerine git pull kullan.
- Değişiklik sitede görünmüyor:
  git pull sonrası Web -> Reload bas.
- Site hata veriyor:
  Web sekmesinde "Error log" bağlantısına bak.
