KARE - PYTHONANYWHERE ÜZERİNDE ÜCRETSİZ YAYINLAMA
=================================================

ÖNEMLİ: Aşağıdaki komutlar KENDİ BİLGİSAYARINDAKİ cmd'de DEĞİL,
PythonAnywhere sitesindeki Bash konsolunda yazılır.
Bilgisayarına Git kurmana gerek yok.

GEREKSİNİMLER
-------------
- Ücretsiz PythonAnywhere hesabı
- Kodun GitHub'da olması: https://github.com/HAKANMAZI/ClaudeNotes (kare klasörü)

KURULUM (bir kez yapılır)
-------------------------
1. https://www.pythonanywhere.com adresine gir.
   "Pricing & signup" -> "Create a Beginner account" ile ücretsiz hesap aç.

2. Üst menüden "Consoles" -> "Bash" tıkla. Açılan siyah ekrana yaz:
   git clone https://github.com/HAKANMAZI/ClaudeNotes.git

3. Üst menüden "Web" -> "Add a new web app" -> "Next"
   -> "Manual configuration" -> en yeni Python sürümünü seç -> "Next".

4. Web sayfasında "WSGI configuration file" bağlantısına tıkla.
   İçindeki her şeyi sil, şunu yapıştır
   (KULLANICI yerine PythonAnywhere kullanıcı adını yaz):

   import sys, os
   sys.path.insert(0, '/home/KULLANICI/ClaudeNotes/kare')
   os.environ['SECRET_KEY'] = 'buraya-uzun-rastgele-bir-yazi'
   from app import app as application

   Sağ üstte "Save" de.

5. "Web" sekmesine dön, yeşil "Reload" düğmesine bas.

6. Site adresin: https://KULLANICI.pythonanywhere.com
   Bu adresi arkadaşlarına gönder. "Kayıt ol" ile kendi hesaplarını açarlar.

GÜNCELLEME (kodu değiştirdiğinde)
---------------------------------
1. Değişiklikleri GitHub'a yükle.
2. PythonAnywhere -> "Consoles" -> "Bash":
   cd ClaudeNotes
   git pull
3. "Web" sekmesi -> "Reload".

AYLIK BAKIM
-----------
Ücretsiz hesapta site bir ay kullanılmazsa kapanır.
Ayda bir kez "Web" sekmesindeki süre uzatma düğmesine bas
("Run until ..." yazan düğme).

SINIRLAR (ücretsiz plan)
------------------------
- Bir web uygulaması
- Beş yüz on iki megabayt disk (veritabanı ve fotoğraflar dahil)
- Veriler kalıcıdır, silinmez.

SORUN GİDERME
-------------
- "git is not recognized": Komutu kendi bilgisayarında yazmışsın.
  PythonAnywhere'deki Bash konsolunda yaz.
- Site hata veriyor: "Web" sekmesindeki "Error log" bağlantısına bak.
- Değişiklik görünmüyor: "git pull" sonrası "Reload" basmayı unutma.
