# Radyo

Tarayıcıda çalışan internet radyosu. `index.html` dosyasını açmanız yeterli.

- Ülkeye ve türe göre istasyon listesi (Radio Browser API)
- İsimle arama
- Favoriler (tarayıcıda saklanır)
- Çal / durdur, ses ayarı
- Arama tüm radyolarda yapılır
- Yayın akışı için istasyonun web sitesine bağlantı
